# ☀️ Morning Routine Timer

An elegant, neumorphic-style morning routine manager built with **Next.js 14**, **Tailwind CSS**, and **Lucide Icons**. 
This app helps you stay on track with your morning activities with a built-in timer, progress tracking, and audio notifications.

## ✨ Features

-   **Neumorphic UI:** A soft, modern design that feels tactile and clean.
-   **Smart Timer:** Automatically advances to the next task when time is up.
-   **Audio Alerts:** A "Ding" sound plays at the end of each task to keep you focused.
-   **Dark Mode:** Full support for dark and light themes with a stylish toggle.
-   **Dynamic Greeting:** Personalized greetings based on the time of day.
-   **Progress Tracking:** Visual progress rings for individual tasks and an overall progress bar for the entire routine.
-   **Mobile Ready:** Designed as a PWA (Progressive Web App) for a native feel on iOS and Android.

## 🛠️ Tech Stack

-   **Framework:** Next.js 14 (App Router)
-   **Styling:** Tailwind CSS (with Custom Neumorphic Utilities)
-   **State Management:** React Context API & Reducer
-   **Icons:** Lucide React
-   **Theme:** Next Themes
-   **Deployment:** Vercel
